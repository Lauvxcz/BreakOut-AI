# Breakout AI

A personal Python project to build a Breakout game and develop an AI agent that learns to play it.

## Planned Features

- Breakout gameplay with custom ball physics, paddle controls, and a combo-based scoring system
- A rule-based bot and a reinforcement learning agent
- An optional debug panel for positions, velocity vectors, game statistics, and neural network activations
- Training statistics and comparisons between different agents

## Project Status

🚧 **Early development** — currently planning the game mechanics and setting up the project.

## Development Philosophy

My goal is to write **nearly 100% of the project's source code myself**. I may use AI tools to learn concepts, discuss approaches, review my work, or study examples, but I do not copy AI-generated code into the project, with the exception of AI-assisted code completion provided by my IDE.

## Planned Tech Stack

Python · pygame-ce · PyTorch
